## 4. How this file is kept honest

- `npm run engine:build` recomputes artifact hashes and the link inventory.
- `npm run licenses:collect` regenerates `licenses/` from the pinned sources; CI fails when the committed copy differs.
- `npm run licenses:check` scans every installed npm package against an SPDX allow-list; exceptions live in `scripts/license-exceptions.json` with a written reason.
